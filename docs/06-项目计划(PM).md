## 一、项目概述

一站式整合 deepthinkstock（策略/持仓）+ deepthinkSingle（行情/稳定性），新增"持仓/推荐 → 个股详情"一键衔接。**核心策略：复用已验证代码，不重写**。

- 周期：**16 个工作日**（含文档 2 天）
- 团队：单人（本人，AI 辅助）
- 交付：可运行 Web 平台 + 完整文档 + 测试基线

## 九、评审后改造计划（2026-09-10 追加）

> 立项阶段（M0~M5）已完成。2026-09-10 完成策略引擎与架构评审后，新增本轮改造计划。**详细内容见 [09-改造实施方案.md](./09-改造实施方案.md)**，本节仅作计划索引。

### 9.1 与原计划的差异

| 维度 | 原计划（M0~M5） | 本轮改造 |
|---|---|---|
| 目标 | 从 0 交付可用系统 | **提升既有系统的信号时效与风控能力** |
| 范围 | 全量功能开发 | R1~R12 定点改造（约 100 行核心改动） |
| 周期 | 16 工作日（含 20% 缓冲） | **6 周（W1~W6），约 16 人日，按每周 2.5~3 人日兼职排期** |
| 建模 | 无 | **明确排除**（LSTM/Transformer/RL/因子挖掘均不做） |

### 9.2 里程碑

| 里程碑 | 时点 | 内容 | 验收 |
|---|---|---|---|
| **M1** 数据时效 + 风控底线 | W2 末 | R1 季报 TTM、R2 行业/板块上限、R3 硬止损、R4 OHLCV | 财报滞后 ≤6 个月；建仓无同行业、单板块 ≤2；止损规则覆盖 100% 持仓卡 |
| **M2** 执行质量 + 评分可信 | W4 末 | R5 整数手分配、R6 Scorecard 2.0 | 资金利用率 ≥95%；观察池评分区分度恢复且可归因 |
| **M3** 回测可信 | W6 末 | R8 成交/成本修正、R7 双轨宇宙、R9 工程债(部分) | 成交改 t+1 开盘；输出含退市股的真实回撤；日志符合规范 |

### 9.3 停止条件（沿用原计划 §7.5）

任一里程碑验收不达标即**暂停排障，不强行推进**。特别地：

- R1 季报 TTM 若导致买仓清单出现异常（如合格池数量骤变 >50%），暂停并人工复核财报时点对齐逻辑；
- R6 评分卡上线后，若观察池评分区分度未改善（仍大量同分），视为未达标；
- R7 引入退市股后回测指标"变差"属**预期结果**（修正偏差），不视为未达标。
