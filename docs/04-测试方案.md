## 五、核查中发现的 bug（DOM 级测试立功）

1. **stock.js `$` 未定义（严重）**：stock.js 是 ES Module，看不到 app.js 普通 script 的顶层 `const $`。真实浏览器点开个股详情页第一行就 ReferenceError 崩溃。已修：stock.js 自包含 `const $ = document.querySelector`。
2. **renderCardTable 表头裸 `<tr>`**：表头未包 `<thead>`，浏览器自动塞进 tbody。已修：`<thead>/<tbody>` 分离。
3. **renderRecs 缺 `<table>` 包装**（上轮已修，本轮纳入回归）。
