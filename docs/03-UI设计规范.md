## 一、设计原则

1. **交易终端信息密度**：一屏看全决策所需信息，不牺牲信息换美观
2. **层次分明**：数字/涨跌 > 文字描述 > 辅助说明，信息优先级通过字号/颜色/加粗表达
3. **红涨绿跌（中国习惯）**：涨=红、跌=绿（区别于欧美，**必须遵守**）
4. **浅色专业主题**：白底卡片 + 蓝主色，清晰易读（延续 deepthinkstock）
5. **一致性强**：所有表格/卡片/徽章风格统一，间距/圆角/阴影有系统 token

## 四、组件规范

### 4.1 按钮

| 类型 | 样式 | 用途 |
|------|------|------|
| 主按钮 | 蓝底白字 `#2563eb` | "保存并分析" |
| 次按钮 | 白底灰边 | "打开报告"/"刷新" |
| 危险按钮 | 白底红边红字 | "删除选中" |
| 禁用 | 降低透明度 0.55 | 任务运行中 |

### 4.2 表格（核心组件）

```css
table { width:100%; border-collapse:collapse; font-size:13px; }
th { background:#f9fafb; color:#6b7280; font-weight:600; padding:8px 10px; }
td { padding:8px 10px; border-bottom:1px solid #f3f4f6; }
tr:hover td { background:#f9fafb; }
```

**股票代码单元格（可点击）**：
```css
td[data-code] { cursor:pointer; color:#2563eb; font-weight:600; }
td[data-code]:hover { text-decoration:underline; background:#eff6ff; }
```

**列对齐**：数字列右对齐（tabular-nums）；文字列左对齐；涨跌列带色。

### 4.3 徽章（Tag）

| 徽章 | 用途 | 样式 |
|------|------|------|
| `⭐精选` | 本周最值得买入 | 橙底 `#fff7ed` + 橙字 `#c2410c` |
| `已持仓` | 当前持仓 | 红底 `#fef2f2` + 红字 `#b91c1c` |
| `占预算 52%` | 精选行资金占用 | 蓝底 `#eff6ff` + 蓝字 `#1d4ed8` |
| `超预算 138%` | 更多候选未入选原因 | 橙底 + 橙字，加粗 |
| `定投` | 持仓定投标记 | 绿底 `#d1fae5` + 绿字 |
| 市场标签 | 沪/深/北交所 | 各自颜色底白字 |

### 4.4 建议标签（操作卡/推荐）

| 建议 | 样式 |
|------|------|
| 加仓/买入 | 绿底绿字 `#d1fae5`/`#047857` |
| 持有 | 蓝底蓝字 |
| 减仓/清仓 | 红底红字 |
| 观望 | 黄底黄字 |

## 六、交互规范

| 交互 | 规范 |
|------|------|
| 代码点击 | 蓝字 → hover 下划线 + 浅蓝底 → 跳转 hash 路由 |
| 持仓行选中 | 点击行 toggle，选中行浅蓝底 `#eff6ff` |
| 保存并分析 | 提交后按钮禁用 + 进度条动画 + 状态文字 |
| 分析完成 | 进度条变绿 + toast"分析完成" + 自动刷新各 Tab |
| 删除确认 | `confirm()` 弹窗 + 显示将删除数量 |
| 数据源降级 | 页面顶部黄色横幅"⚠ 东财兜底中"（来自 sysinfo） |
| 空态 | 每 Tab 都有明确空态文案 + 引导下一步 |
| 超预算提示 | 更多候选行显示橙色"超预算 138%"徽章 |

## 七、可访问性与可用性

1. **字号**：正文 ≥13px，数字 ≥13px（tabular-nums）
2. **对比度**：文字 vs 背景 ≥ 4.5:1（次要文字 3:1）
3. **键盘导航**：Tab 键可切换 Tab；Enter 触发代码跳转
4. **加载态**：异步数据未返回时显示骨架屏/loading，避免布局跳动
5. **错误态**：单卡片失败显示占位 + 重试按钮，不影响其他卡片

## 八、UI 评审意见（UI大师）

1. **配色一致性**：全站只用一套 Token，禁止硬编码色值（除 ECharts 图表配置外）
2. **图表与行情色冲突**：回测柱状图的"绿正红负"与行情"红涨绿跌"易混淆——回测图用"蓝=优/灰=劣"或图例显式标注"正收益=绿"，待用户确认
3. **信息密度**：个股详情页 8 卡片默认展开，但提供"折叠模式"（只看概况+分时）
4. **移动端**：Sidebar 折叠后持仓表横向滚动，详情页卡片单列堆叠
5. **深色模式**：预留 `[data-theme="dark"]` 变量覆盖（本期不实现，架构预留）
