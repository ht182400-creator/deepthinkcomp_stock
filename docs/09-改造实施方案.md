## 1. 场景与约束（决定本方案的一切取舍）

| 维度 | 设定 | 对方案的约束 |
|---|---|---|
| 本金 | 10~15 万 | 单仓 3~7 万，最低佣金 5 元 = 0.007%~0.017%，**可忽略** |
| 下单 | 人工 | 无法高频执行；可执行规则（止损/分批）；**可做人脑终审** |
| 持仓 | 2~4 只 | 分散度靠**行业/驱动逻辑**，不靠数量 |
| 频率 | 周频信号，人工择时 | 模型定位 = **初筛器**（1689 → 7 只），人做终审（7 → 2~4 只） |
| 人力 | 1 人（兼职） | 按每周 2.5~3 人日排期；排除高维护成本方案 |

**核心定位（重要）**：本方案的目标不是"让模型替你决策"，而是 **"让初筛更及时、更准，并给人工决策配上风控护栏"**。人的信息集（公告、业务逻辑、政策、K 线形态）远大于 5 个因子，这是人工操作相对全自动量化的结构性优势。

| LSTM / Transformer / 时序深度学习 | 信噪比 <2%，容量严重过剩；需 GPU 与数天调参；单人不可维护 |
| 强化学习 | 10~15 万资金无市场冲击，RL 建模对象不存在；极不稳定不可解释 |
| 因子自动挖掘（遗传规划） | 必然产出过拟合因子，需多重检验校正，工具链成本数周 |
| QLib 引入 | 重依赖 + 数据格式转换，收益与自建 GBDT 相当 |
| 组合优化器 / 协方差矩阵 | 人工 2~4 只场景，约束规则（R2）比优化器更有效且可解释 |
| 波动率目标仓位 | 人工可自行决定仓位，暂不需要自动化；列入 Backlog 视需要再开 |
| 手工逆向解析 `cw/gpsh*<代码>.dat`（按个股，6988 个） | 字段未公开、mootdx 不支持，需自行逆向 → **不做** |
| 接入 baostock 补退市股财务 | 退市股财务免费渠道不可得（本地 cw 与东财**双向实测确认**），改用 R7 双轨方案 |

> ⚠️ **注意区分 `cw/` 下两类文件**：`gpsh*/gpsz*/gpbj*<代码>.dat`（按个股）→ **不解析**；`gpcw<报告期>.dat`（按报告期，148 个）→ **用 mootdx 直读，已作为 R1 主方案**。v1.0 中"不解析 cw"的表述已作废。

### R1b · 业绩预告补齐（东财批量接口）【P1 · 0.5 人日】

**背景**：官方 FN 表含业绩预告/快报字段（FN285~294 等 14 列），但 `gpcw` 中这些列**填充率仅 0.1%**（几乎全空）→ **本地拿不到前瞻信号**。实测东财接口可用且**按报告期批量**。

**实测（2026-09-10）**：东财 `RPT_PUBLIC_OP_NEWPREDICT`，`filter=(REPORT_DATE='2026-06-30')` 一次返回 **4901 条**全市场预告，字段完整：

| 字段 | 含义 |
|---|---|
| `NOTICE_DATE` | **披露日**（时点对齐用） |
| `REPORT_DATE` | 对应报告期 |
| `PREDICT_FINANCE` | 预测指标（如"归属于上市公司股东的净利润"） |
| `PREDICT_AMT_LOWER / UPPER` | 预告净利**下限 / 上限** |
| `ADD_AMP_LOWER / UPPER` | 同比增幅上下限(%) |
| `PREDICT_TYPE` | 预告类型（预增/扭亏/预减/首亏…） |
| `PREDICT_CONTENT` | 文字描述 |

**价值**：把"最新经营情况"的滞后从 TTM 的 **4 个月压到约 1 个月**（预告比正式财报早 1~1.5 个月披露）；A 股存在显著的**盈余公告后漂移（PEAD）**效应 → 真实 alpha 来源。

**实现要点**
1. 新建 `data/forecast.py`：按**报告期循环**拉取（近 5 年约 20 期 → 20 次请求，秒级完成），落盘 `data/forecasts.json`。
2. **时点对齐**：必须用 `NOTICE_DATE`，**禁止用 `REPORT_DATE`**（否则前视偏差）。
3. **区间处理**：取中值 `(lower+upper)/2` 作点估计，同时保留上下限作为"不确定性"因子。
4. **覆盖率说明**：A 股仅对"净利润为负/扭亏/变动 ≥50%"等情形强制预告 → 覆盖约 88%（4901/5561）。**这反而使预告成为"异常信号筛选器"**，天然聚焦于经营显著变化的公司。
5. 用途（可并用）：
   - **风险规避**：`PREDICT_TYPE ∈ {预减, 首亏, 续亏}` → 从买池剔除；
   - **预期因子**：`ADD_AMP`（预告同比增幅）纳入 R6 评分卡的"成长/预期"维度。

**验收**
