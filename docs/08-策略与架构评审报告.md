## 0. 结论摘要（TL;DR）

**有更先进的模型可用，但当前瓶颈不在模型先进度，而在数据时效性与风控规则的缺失。直接上 LightGBM/QLib 只会更快过拟合。**

### 0.1 场景前置说明（决定全部优先级）

| 维度 | 本项目的实际设定 | 对方案的影响 |
|---|---|---|
| 本金 | **10~15 万** | 最低佣金 5 元 = 单笔 0.007%~0.017%，**可忽略**，无需为佣金降换手 |
| 下单方式 | **人工操作**（非自动量化） | 无法高频执行；但可执行规则（止损/分批）；**可做人脑终审** |
| 持仓数量 | **2~4 只** | 单仓 25%~40%，分散度靠**行业/驱动逻辑**而非数量 |
| 调仓频率 | 周频信号，人工择时执行 | 模型定位应为**初筛器**，不是决策者 |
| 维护人力 | 1 人 | 排除一切高维护成本方案（DL/RL/因子挖掘/重框架） |

> **因此 v1.0 中"N 提到 8~10"的建议已撤回**：人工操作 8~10 只既研究不过来，又稀释了单仓意义。2~4 只合理，前提是必须配套 §0.2 的三条规则。

### 0.2 按"投入产出比"重排的最高优先级（人工场景版）

| 级别 | 问题 | 影响 | 建议动作 | 改动量 | 预估收益 |
|---|---|---|---|---|---|
| **P0** | **质量因子滞后 16 个月**：财报只取年报，季报被 `fetch_fund_broad.py:80` 主动丢弃 | 用 16 个月前的 ROE 给当下打分 | **删掉 1 行过滤**，改存季报 + 算 TTM | **1 行 + ~30 行** | **收益提升最大、成本最低** |
| **P0** | **实盘无行业/板块上限**：2026-09-04 建仓 3 只**全是 688 科创板** | 名义 3 只、实质 1 只，等于加杠杆 | 新增行业 ≤1 只、单板块 ≤2 只约束 | ~30 行 | 直接降低组合波动 |
| **P0** | **无硬止损**：2~4 只组合单票 -50% ⇒ 整体 -12.5%~-25%，回本需 +28%~+67% | 人工操作刚需 | 单票 -15% 减半、-25% 清仓 | ~15 行 | 限制尾部亏损 |
| **P1** | **日频 OHLCV 被丢弃**：`build_universe_layer2` 只存 close | 无法算波动率/换手率/流动性因子 | 保留 6 字段 | **1 行** | 解锁风控与流动性过滤 |
| **P1** | **资金利用率仅 70.6%**：逐仓整除，剩余现金不二次分配 | 30% 资金闲置拖累收益 | 整数手贪心分配 | ~20 行 | 利用率 → 95% |
| **P2** | **评分是两套尺子**：入选用模型分、未入选硬编码 45/50/58/30 | 观察池 113 只全 50 分，信息量为零 | Scorecard 2.0 统一评分卡 | ~50 行 | 排序质量与可解释性 |
| **P2** | **幸存者偏差**：宇宙无退市股 | 回撤 -56% 被低估，真实更差 | 双轨宇宙（详见 §7-Q3） | ~40 行 | 拿到真实风险数字（**不提升收益**） |
| **P3** | 因子权重 0.5/0.5 拍脑袋 | 权重无数据依据 | IC/IR 诊断 + 权重优化 | 中 | 夏普 +0.1~0.3 |
| **P4** | 需要非线性建模 | 线性模型表达力上限 | LightGBM（需前置全部完成） | 大 | 有争议，必须与基线对照 |

**关于"更先进模型"的明确结论**：走 **"修数据时效（P0）→ 补风控规则（P0/P1）→ 因子诊断（P3）→ 最后才考虑 GBDT（P4）"** 的路线。反过来做会得到一个在回测里很漂亮、实盘立刻失效的模型。

**关于模型角色的结论（重要）**：在本场景下，最优解不是"让模型替你决策"，而是 **机器做初筛（1689 → 7 只）+ 人做终审（7 → 2~4 只）**。人的信息集（公告、业务逻辑、政策、K 线形态）远大于 5 个因子，这是人工操作相对全自动量化的**结构性优势**，不应被模型取代。

## 1. 现状盘点

### 1.1 数据流

```
通达信本地 .day（全历史日线）
   └─ decode_gbbq.py → all_xdxr.csv（权息）→ read_qfq() 前复权
        └─ qfq_to_weekly()  → 周线
             ├─ 价格宇宙（1689 只，只保留 close）
             └─ 段指数（sh000001/000985/000688/399006/399001/899050）→ 56 周 MA regime

fundamentals_broad.json（1438 只，东财 DMSK 年报序列，带 NOTICE_DATE）
   └─ pt_fund() → ROE / FCF/NP / ROE 变异系数 / 资产负债率

                ↓
       current_candidates()（实盘信号）  /  run_backtest_layer2()（回测）
                ↓
   质量门(ROE≥10% & FCF>0) + 站上 52 周 MA + 动量>0 + 段 regime UP
                ↓
      rank_normalize 截面排名 → score = 0.5×质量 + 0.5×动量
                ↓
   资金可行性（整手）→ selected → 持仓卡 / 本周推荐 / dashboard HTML
```

### 1.2 策略公式（当前）

```python
# modules/strategy/regime_layer2_backtest.py:596-605
qs    = (roe_rk + fcf_rk + (1 - cv_rk) + (1 - debt_rk)) / 4.0
score = 0.5 * qs + 0.5 * mom_rk
```

即：**4 个质量因子等权 + 与动量 5:5 加权**，权重为人工设定，未经任何 IC/IR 检验。

### 1.3 当前回测基线（`data/results_layer2_fresh.json`）

| 方案 | 年化 | 夏普 | 最大回撤 | 空仓占比 | 换手率 | 窗口 |
|---|---|---|---|---|---|---|
| current（上证 56 周） | 11.39% | 0.503 | **-52.2%** | 45.6% | 13.2% | 全样本 |
| B（分市场段指数，**实盘在用**） | 11.38% | 0.438 | **-56.1%** | 0.0% | 17.5% | 全样本 |
| B | 8.59% | **0.249** | -56.1% | 0.0% | 26.9% | **2014+** |
| C（内生无 regime） | 9.79% | 0.316 | -68.0% | 0% | 20.9% | 全样本 |
| E（上证 200 周尾部） | 2.26% | 0.014 | -74.0% | 45.1% | 13.4% | 全样本 |
| A（中证全指） | 6.72% | 0.292 | -56.7% | 45.3% | 9.1% | 全样本 |

**关键读数**：

1. **Calmar 比率仅 0.20**（11.38% / 56.1%）。长期年化 11.4% 却承受 56% 回撤，风险调整后收益很差。
2. **2014+ 夏普骤降到 0.249**（全样本 0.438），年化降到 8.59%。这是典型的"参数在全样本内挑出来、近年失效"的症状。
3. **B 方案空仓占比 0%**：个股级段 regime 只做"入场过滤"，不做"仓位管理"，2015 / 2018 / 2022 熊市全程满仓 90% 暴露 → 回撤 -56% 的直接来源。
4. 换手率 17.5%/周 ≈ **年换手 9 倍**，在 5 万小账户上成本敏感（见 §2.5）。

## 2. 收益瓶颈诊断（按影响排序）

### 2.1 【致命】幸存者偏差 —— 回测数字不可信

`fundamentals_broad.json` 是 2026 年从东财抓取的**当前在市**股票（`fetch_fund_broad.py` 基于 `daily_broad.json` 的 1020 只 + 已有 500 只合并而来）。而回测从 1996 年跑起：

```python
# modules/strategy/regime_layer2_backtest.py:162-220
def build_universe_layer2(min_weeks=60, include_bj=True):
    fund = json.load(open(os.path.join(WORK, 'fundamentals_broad.json'), ...))
    for code, f in fund.items():   # ← 只有"今天还活着"的股票
```

**后果**：
- 所有**已退市 / 已 ST 摘牌**的股票被系统性剔除。历史样本里只留下"活下来的赢家"。
- "质量 + 动量"策略的历史回撤被**系统性低估**（崩盘的票被剔除了），年化被**高估**。
- 更糟的是：质量门（ROE≥10% & FCF>0）在只有存活样本时显得格外有效 —— 这是自证循环。

**建议**：
- 用 **baostock**（免费、无需注册、含退市股与全历史财报）或 akshare 重建宇宙，至少覆盖 2005 年至今全市场（含退市）代码表 + 年报/季报 + 日频复权行情。
- 通达信 `.day` 可以继续作为**价格源**（质量最好），但**代码表**必须用含退市的全量清单。
- 退市股票的退市日之后收益按"最后可行价格 + 退市整理期折价"处理，不可直接丢弃（否则又是一种偏差）。

### 2.2 【致命】只有"选股"，没有"风险管理"

当前组合层是**等权 + 固定 0.9 暴露**：

```python
# modules/strategy/regime_layer2_backtest.py:336-345
if regime_scope == 'stock':  expo = 0.9
elif market_up:              expo = 0.9
else:                        expo = tail_expo
...
for c in held: w[c] = (1.0 / k) * expo     # 纯等权
```

缺失的风险控制手段（按性价比排序）：

| 手段 | 说明 | 预期效果 |
|---|---|---|
| **波动率目标（Vol Targeting）** | 按组合近 26~52 周已实现波动动态调整 `expo`，如 `expo = min(0.9, target_vol / realized_vol)`，`target_vol=15%` | 最廉价、最有效的回撤改善，通常 MDD 减半、夏普 +0.2~0.3 |
| **个股止损/移动止盈** | 现有退出条件只有"跌破 52 周 MA / 动量 ≤ -40% / 价格分位 ≥85 / 价格 >300"，**没有硬止损** | 限制单票尾部亏损 |
| **组合层面回撤熔断** | 组合从高点回撤 >15% 时强制降到半仓，>20% 清仓观察 | 直接压制 MDD |
| **风险平价 / 最小方差加权** | 用协方差矩阵（Ledoit-Wolf 收缩估计）替代等权，波动大的票给更小权重 | 波动 -10~20% |
| **行业/市值中性化** | 打分在行业内做 z-score/排名，而非全池排名 | 消除"高分=某行业"的系统性偏移 |

> 关键点：**收益 11.4% 不是主要问题，-56% 回撤才是**。Calmar 0.20 的组合在实盘上极难坚持执行。

### 2.3 【高】回测与实盘口径不一致

| 维度 | 回测 `run_backtest_layer2` | 实盘 `current_candidates` | 后果 |
|---|---|---|---|
| 行业上限 | `ind_cap=0.35`（每行业最多 `floor(0.35*N)` 只） | **完全没有** | 实盘可能 4 只同行业，风险 > 回测 |
| 板块/市场约束 | 无 | 无 | 2026-09-04 实盘 **3 只全为 688 科创板** |
| 分数最高的票能否买入 | 不涉及 | `price*100 <= per_pos` 过滤 | 见下 |

**实例证据**（`data/live_buy_list_20260904.txt`）：

```
合格买仓池 7 只：
  688300 联瑞新材  MOM 172.9%  分 0.83  ← 分数第 1，价 163.68，一手 16368 > 单仓预算 11250 → 被剔除
  ★688625 呈和科技 MOM 114.9%  分 0.60  ← 实际买入
  688120 华海清科  MOM 171.0%  分 0.52  ← 价 243.49，被剔除
  ★688127 蓝特光学 MOM  86.1%  分 0.46
  ★688059 华锐精密 MOM  69.6%  分 0.40
  688019 安集科技  MOM  57.6%  分 0.38  ← 被剔除
  688008 澜起科技  MOM  53.2%  分 0.31  ← 被剔除
实际建仓 3 仓，合计 31779 元 / 可投 45000 元
```

三个可量化的问题：

1. **分数最高的票买不了** —— 资金可行性用"能否买 1 手"做硬过滤，等于让**股价**而非**质量**主导选股。7 只里 4 只因价格被砍，最终买的是第 2、4、5 名。
2. **现金拖累 29.4%** —— 可投 45000，实际只投 31779，闲置 13221 元。`lots = int(budget // (price*100)) * 100` 是逐仓整除，剩余资金没有二次分配。
3. **板块 100% 集中** —— 3 只全部科创板 688，同涨同跌，名义 N=4 实际有效分散度约等于 1 个板块。

**建议**：
- 把"选股池 → 目标权重 → 整数手分配"拆成两步：先在**权重空间**做组合优化（连续解），再用**贪心/整数规划**把权重落到 100 股的整数倍，剩余现金按边际收益二次分配（目标：资金利用率 ≥ 95%）。
- 实盘补齐行业上限与板块上限（单一板块 ≤ 50%）。
- 单仓预算不足时应**明确提示用户**（"账户 5 万 + N=4 时，单价 >112 元的股票无法建仓，建议提高 N 或集中资金"），而不是静默剔除。

### 2.4 【高】成交假设偏乐观

```python
# modules/strategy/regime_layer2_backtest.py:347-351
p0 = meta[code]['c'][meta[code]['d'][ti]]       # 第 t 周收盘
p1 = meta[code]['c'][meta[code]['d'][ti2]]      # 第 t+1 周收盘
r += wt * (p1 / p0 - 1)
```

问题：
- **按第 t 周收盘价成交**：信号在周末产生，却以同一根收盘价成交。现实中只能在 t+1 开盘成交。应改为 `t+1 开盘价买入 → t+2 开盘价卖出`（或至少 `t+1 开盘 → t+1 收盘`）。当前写法会吸收一部分"信号已公开后的价格漂移"。
- **无涨跌停 / 停牌处理**：一字涨停无法买入、停牌无法交易，均未建模。
- **成本模型过于简化**：单边 0.12% 只覆盖佣金+印花税，**未含冲击成本**，且**未考虑 5 万小账户的最低 5 元佣金** —— 单笔 1.1 万元的交易，最低佣金 5 元即 **0.045%**，是名义费率 0.025% 的近 2 倍。年换手 9 倍时，这笔开销远超想象。
- **无流动性约束**：没有用成交额（ADV）限制单票持仓占比，小盘股理论上可以买到不可成交的规模。

建议：成本模型改为 `max(成交额 × 0.025%, 5 元) + 卖出印花税 0.05% + 滑点 k×√(Q/ADV)`。

### 2.5 【高】因子体系单薄 + 全部来自年报

现有 5 个因子（`pt_fund` + `mom_metrics`）：`ROE`、`FCF/净利润`、`ROE 变异系数`、`资产负债率`、`52 周动量`。

缺失的关键因子维度：

| 维度 | 现状 | 应有因子 |
|---|---|---|
| 估值 | **无**（`pct_rank_local` 算的是**价格分位**，不是 PE/PB 分位，命名有误导） | PE/PB/PS/PCF 及其历史分位、股息率 |
| 成长 | **无**（只有 ROE 水平，无增速） | 扣非净利同比/环比、营收增速、ROE 变化率 |
| 波动/风险 | **无** | 1 年已实现波动、下行波动、Beta、最大回撤 |
| 流动性/量价 | **无**（`build_universe_layer2` 只保留 `close`，**丢弃了 open/high/low/volume/amount**） | 换手率、Amihud 非流动性、成交额、量价背离 |
| 规模 | 仅 `price_cap=300` 的价格过滤（价格 ≠ 市值） | 总市值/流通市值对数 |
| 情绪/资金 | 无 | 北向持股变动、融资余额变化、龙虎榜 |

**数据侧的硬约束**：

```python
# modules/strategy/regime_layer2_backtest.py:181
spk = {b['pkey']: b['close'] for b in wk}   # ← 只保留收盘价
```

要支持上面任何一个量价因子，必须把 `open/high/low/volume/amount` 一起保留（磁盘/内存成本可接受：1689 只 × 1588 周 × 6 字段 ≈ 1600 万 float，用 numpy float32 约 64MB）。

另外财报只取 `-12-31` 年报（`fetch_fund_broad.py:80`），且 `pt_fund` 要求 ≥3 期。年报最晚 4 月底披露 → **质量因子最长滞后 16 个月**。应引入季报滚动 TTM。

### 2.6 【中高】参数全部在全样本内选定，无样本外验证

52 周动量、56 周 MA、`ROE≥10%`、`price_cap=300`、`ind_cap=0.35`、`N=15`、0.5/0.5 权重 —— 全部是同一份数据上反复调出来的，且 `2014+` 窗口夏普从 0.438 掉到 0.249 已经给出了警告信号。

当前**完全没有**：
- 样本外 / walk-forward 测试
- Purged K-Fold + Embargo 的时序交叉验证（金融标签有持有期重叠，标准 K-Fold 会泄漏）
- 因子 IC / ICIR / 分层回测（quantile portfolio）诊断
- 多重检验校正（Deflated Sharpe Ratio）
- 与基准（沪深 300 / 中证 500）的 alpha-beta 归因

**建议**：先建一个 `research/` 目录，把"因子研究"与"生产信号"彻底分离。研究环境输出 IC/IR 报告与分层收益图，只有通过验证的因子才允许进入 `current_candidates`。

## 3. 评分体系诊断（前端 score）

### 3.1 现状

```python
# modules/holdings/holdings.py:112-136
if   code in sel_map:  score = score*100, advice="加仓"
elif code in buy_map:  score = score*100, advice="持有"
elif code in obs_map:
    if   "段regime" in fail: score = 50.0, advice="减仓"
    elif "动量负"   in fail: score = 45.0, advice="减仓"
    elif "未站线"   in fail: score = 58.0, advice="持有"
    else:                    score = 50.0, advice="观望"
else:                        score = 30.0, advice="清仓"
```

### 3.2 问题

1. **评分不连续、不可比**：入选股用模型分（0~100），未入选股用硬编码常量 45/50/58/30。用户看到的"评分"其实是两套完全不同的尺子拼起来的。
2. **观察池 113 只，评分全是 50** —— 2026-09-04 的观察池里，紫金矿业（ROE 20.9%）、洛阳钼业（20.4%）、药明康德（23.9%）与一堆平庸股票并列 50 分，信息量为零。
3. **无评分归因**：用户不知道分数是怎么来的，无法判断该不该信。
4. **评分与"建议"的映射是拍脑袋的**：为什么 58 分是"持有"、45 分是"减仓"？没有回测校准依据。

### 3.3 建议：统一评分卡（Scorecard 2.0）

所有股票（入选 / 观察 / 持仓）都用**同一套**因子分位计算总分，并拆解展示：

| 维度 | 权重（初始建议） | 子因子 |
|---|---|---|
| 质量 Quality | 30% | ROE(TTM)、FCF/净利、资产负债率、ROE 稳定性 |
| 动量 Momentum | 25% | 52 周动量、12-1 动量、相对行业强弱 |
| 成长 Growth | 20% | 扣非净利同比、营收同比、ROE 变化 |
| 估值 Value | 15% | PE/PB 历史分位、PEG |
| 风险 Risk | 10% | 已实现波动、Beta、流动性（ADV） |

配套要求：
- **分数 = 加权分位（0~100）**，权重用 IC/IR 优化得到，而非拍脑袋；
- **财报时效衰减**：质量/成长分随财报披露日距今的月数线性衰减，避免用 16 个月前的年报给当下打高分；
- **阈值回测校准**：用历史数据回测"不同评分档位的未来 N 周收益"，据此定 80/60/40 的加仓-持有-减仓-清仓阈值；
- **前端展示评分归因**：`总分 72 = 质量 85 × 30% + 动量 90 × 25% + 成长 60 × 20% + 估值 40 × 15% + 风险 55 × 10%`，并标注"财报更新于 2026-04-28（时效衰减 -12%）"。

## 4. "更先进的模型"评估矩阵

| 方案 | 适配度 | 前置条件 | 预期提升 | 维护成本 | 结论 |
|---|---|---|---|---|---|
| **因子权重优化**（最大化 IR 的线性组合 / IC 加权 / 主成分合成） | ★★★★★ | 需要先有 IC 诊断 | 夏普 +0.1~0.3 | 低 | ✅ **优先做**，替代 0.5/0.5 拍脑袋 |
| **波动率目标 + 风险平价** | ★★★★★ | 需要日/周收益序列 | MDD 减半 | 低 | ✅ **优先做** |
| **组合优化器**（MV / BL / 带约束） | ★★★★☆ | 需要协方差矩阵（Ledoit-Wolf 收缩） | 夏普 +0.1~0.2 | 中 | ✅ 做，可用启发式替代求解器 |
| **LightGBM / XGBoost（GBDT）** | ★★★★☆ | **需要 ≥30 个因子 + Purged CV** | 夏普 +0.2~0.5（有争议） | 中 | ✅ 但**必须排在 P0/P1 之后** |
| **QLib（Alpha158 + LGBM / GRU / Transformer）** | ★★★☆☆ | 需要把通达信数据转成 QLib 格式 | 与上者相当，胜在工程完备 | 高（引入重依赖） | ⚠️ 作为 P3 备选，先做小规模试点 |
| **排序学习（LambdaMART / rank_xendcg）** | ★★★★☆ | 同 GBDT | 对 Top-N 选股更契合 | 中 | ✅ 若上 GBDT，优先用排序目标而非回归 |
| **因子挖掘（遗传规划 / RD-Agent）** | ★★☆☆☆ | 需要有研究流水线 | 不确定 | 高 | ❌ 单人项目暂不建议 |
| **LSTM / Transformer / 时序模型** | ★★☆☆☆ | 大量数据 + GPU | 在 A 股周频上增益不明确 | 高 | ❌ 不建议 |
| **强化学习** | ★☆☆☆☆ | — | 极不稳定 | 极高 | ❌ 明确不建议 |

### 为什么不建议现在直接上 GBDT？

当前可用于建模的输入只有 **5 个因子 × 1438 只 × 1588 周**，且其中 4 个来自**年报快照**、存在**幸存者偏差**。在这个基础上训练非线性模型，模型会：

1. 记住"哪些股票活到了 2026 年"（标签泄漏）；
2. 对 5 个维度的交互项过拟合；
3. 产出一个回测 IC 0.08、实盘 IC 0.01 的模型。

**顺序必须是**：修数据 → 补因子 → 做 IC 诊断 → 线性基线 → 再上非线性。且有非线性模型后，**必须保留线性基线做对照**，若 GBDT 相对基线的提升 < 阈值（如 IC 提升 < 0.01），就回退基线。

实测抽样（2025 半年报，数据正确）：

| 代码 | ROE | EPS | 每股净资产 | 资产负债率 | 归母净利 |
|---|---|---|---|---|---|
| 600519 贵州茅台 | 19.02% | 36.18 | 189.98 | 14.75% | 454.0 亿 |

**改用本地 `gpcw` 的收益**：零网络依赖（不受限流/封 IP 影响）→ 148 期完整季报（1988 年至今）→ **585 个字段**（当前仅用 6 个）→ 一次性解析约 1 分钟。

**必须注意的 5 个坑**（源自公开实践与本次实测）：

1. **单位是"元"不是万元**：大额需 ÷1e8 转亿（误用 ÷1e4 会差 1 万倍）。
2. **年报与季报列名含义不同**：年报的 `营业收入` 列存的是 **Q1 单季度值**，全年营收必须用 `营业总收入(万元)` 列（÷1e4 转亿）；季报用 `营业收入`（元）。
3. **季报是累计值**（年初至今），不是单季值 → 算 TTM 需自行差分：`单季 = 本期累计 - 上期累计`。
4. **部分列返回 `pd.Series`**（列名重复导致），需 `.iloc[0]` 取值，否则 EPS 会读成 0。
5. **`五、净利润` 是合并报表**（含少数股东权益），归母必须用 `归属于母公司所有者的净利润`。
6. **最新季报文件可能不完整**（如某半年报仅含 114 只），**年报文件最全**（约 5417~5520 只）；取数时应以年报为基准、季报作增量。

**仍缺什么**：① **退市股**（实测确认无，见 §6.1）；② **披露时点 NOTICE_DATE**（`gpcw` 只有报告期，无实际公告日 → 时点对齐需按法定最晚披露日推断：年报 4/30、半年报 8/31、三季报 10/31、一季报 4/30）。

### 6.5 `gpsh*.dat` / `gpsz*.dat` 是什么、有什么用、为什么不用

**它是什么**：通达信「专业财务数据」（软件内输入 `.401` 看到的那些表），**按个股**存储，每只股票一个文件。

实测结构（茅台 `gpsh600519.dat`，0.33MB / 26753 条；新股 `gpsz301159.dat`，0.16MB / 12604 条）：

- 记录定长 **13 字节** = `1 字节` + `4 字节日期(int32 LE)` + `4 字节值` + `4 字节`；
- 全部股票均为 **35 个字段组（块）**，按"日期序列重置"切分；
- **块 0 = 季度财务**（茅台 105 期：20011231→20260630；新股 301159 仅 23 期，因其 2021 年上市）；
- **其余多为日序列**：如块 1 为 2000 条（20180615→20260909，≈8 个交易年）、块 7 为 2002 条、块 8/9/12/15/18/20/34 各约 2000 条；
- 少数为稀疏序列（2~31 条，如年度/事件类）。

**理论上能提供的日频数据**（通达信 `.401` 内含）：股本结构、股东户数、机构/基金持股、融资融券、分红送配、大宗交易等。

**为什么本项目暂不用**：

1. **字段含义未公开**，且 `mootdx` 不支持（其 `FinancialReader` 仅支持 `gpcw*.dat`）；需自行逆向 35 个块的含义，成本高且易错。
2. **我们需要的日频指标有零成本替代路径**：
   - 总股本 → `gpcw` 每季度都有 `总股本` 字段（实测茅台 = **1,250,081,664 股**）；
   - 日市值 = 日收盘价 × 当期总股本（股本季度内基本不变，误差远小于因子噪声）；
   - **PB = 现价 / `每股净资产`**（`gpcw` 有）；**PE = 现价 / EPS_TTM**；
   - 或直接用腾讯行情接口已返回的**总市值/流通市值**（项目 `/api/quote` 已在用）。
3. 结论：**要拿"日频估值因子"，不必碰 `gpsh`**。

**什么时候值得回来逆向它**：若将来要做**日频情绪/资金因子**（股东户数变化、融资余额变化、机构持仓变化 —— 均为 R6 评分卡的候选因子）。届时可沿用本次验证过的方法——**用已知值反查块偏移**：拿茅台总股本 `1,250,081,664` 去匹配各块末值，定位"每日股本"块后，全市场通用。预留约 2~3 人日。

#### 6.6.4 `gpsh*.dat` 文件结构（实测）


**原理**：用 `gpcw` 中已知的权威值，反查 `gpsh` 各块末值，容差 0.5% 即命中。

| **筹码/情绪** | `股东人数(户)`、`第一大股东的持股数量`、`已上市流通A股`、`自由流通股(股)`、`第一大流通股东持股量(股)` | ★★ 集中度与拥挤度 |

**❌ 不可用清单（有列但无数据）**

| 字段类别 | 填充率 | 原因 |
|---|---|---|
| **业绩预告 / 业绩快报（14 列）** | **0.1%** | 需额外下载或该数据功能未开通 → **本项目拿不到前瞻信号** |
| 机构持股明细（QFII/券商/保险/社保/私募/年金/信托持股量等，33 列） | 24.9% | 机构数据仅在年报/半年报较完整，季报大面积缺失；高填充的仅 5 列（机构总量、机构持股总量、基金机构数、基金持股量、第一大流通股东持股量） |
| 金融类/特殊科目（177 列全 0） | 0% | 银行/券商/保险专用科目，本轮宇宙已剔除金融股（`is_financial`），对策略无影响 |
| 北向资金、审计意见、财务总评分 | 列不存在 | `gpcw` 未提供（北向需另接口；审计意见 FN336、总评分 FN362 官方有但本地包未含） |

**结论（直接回答"其他 FN 字段是否需要"）**

1. **需要，而且是一大笔免费因子**：至少 **40~50 个高价值字段**（成长 9 个 + 比率 47 个中的核心 + 现金流 19 个 + 筹码 5 个）可直接支撑 R6 评分卡的全部五个维度，**无需任何额外数据源**。
2. **也有一批确实不可用**：业绩预告/快报（0.1%）、机构持股明细（24.9%）、金融类科目（全 0）。
3. **对 R1 的影响**：落盘字段应从原定 15 个**扩展为约 35~40 个精选字段**（见 [09 R1](./09-改造实施方案.md)）；其余按需直接读 `gpcw`（**0.4s/期**，读全部 148 期约 1 分钟，无需长期存储全量）。

#### 6.6.7 结论

- `gpsh/gpsz` **确为"FN/GPJY 字段的时间序列"**（季度财务 + 日频交易类数据混合），理论上含股东户数、股本、机构持股、两融等**日频**数据；
- 但 **`gpcw` 的 585 列已覆盖本项目所需的绝大多数字段**（含公告日期、TTM、股东人数、机构持股），故 `gpsh` 的边际价值进一步降低；
- **暂不解析**。若将来需要"日频"版本（如每日总市值、每日股东户数变化、每日两融），再按 §6.6.5 方法系统性定位，预留 2~3 人日。

## 7. 常见疑问答疑

### Q1：LSTM / Transformer / 强化学习 / 因子自动挖掘，为什么明确不建议？

**核心原因只有一条：信噪比与模型容量必须匹配。**

A 股周频截面收益中，因子能解释的比例（R²）通常**不到 2%**，其余约 98% 是噪音。模型容量必须与信噪比匹配：

| 模型 | 典型参数量 | 在本场景下的表现 |
|---|---|---|
| 线性打分（当前） | 5 个权重 | 欠拟合，但稳定、可解释 |
| **GBDT** | 数千~数万 | **容量匹配，这是甜点区** |
| LSTM | 十万~百万 | 开始拟合噪音 |
| Transformer | 百万~亿 | 严重过拟合，需 GPU + 数天调参 |

逐项说明：

- **LSTM / Transformer**：擅长"长序列中存在强规律"的任务（语音、语言、机器翻译）。金融序列恰好相反——规律弱、非平稳，且制度会突变（涨跌停规则调整、注册制、量化监管新规），历史模式会失效。学术上 Gu/Kelly/Xiu(2020) 确实发现神经网络优于线性模型，但其增益**主要来自非线性交互项**，而这部分 GBDT 已能获取大部分，成本却只有十分之一。更现实的约束：调一次 Transformer 需数小时至数天，而喂给它的仍是当前这 5 个有偏差的因子——**垃圾进，垃圾出，只是更精致的垃圾**。
- **强化学习**：RL 的前提是"智能体的动作会影响环境"（存在市场冲击）。10~15 万资金的冲击成本约等于 0，RL 最核心的建模对象不存在。此外 RL 训练极不稳定、不可解释、难以复现。业界真正用 RL 的落地场景是**做市与拆单执行算法**，不是选股。
- **因子自动挖掘（遗传规划 / 公式化因子）**：最危险的一项。它会在数千个候选公式中挑出回测最优者，而**纯随机数据也能"挖"出年化 20% 的因子**。要压制必须做多重检验校正（Deflated Sharpe Ratio），这套统计工具链本身需数周搭建。单人项目做这个，产出几乎必然是过拟合因子。

> **诚实的边界**：以上判断是**性价比判断**，不是"无效判断"。这些技术在顶级机构有用武之地（有团队、有算力、边际收益足够大）。对单人维护的 10~15 万账户，把它们排在最前面就是自找麻烦。

### Q2："直接上 GBDT" 是什么意思？我人工选评分最高的 2~4 只为什么可以？

**"直接上 GBDT" 的含义**

当前模型是**人工拍定权重的线性公式**：

```python
# modules/strategy/regime_layer2_backtest.py:604-605
qs    = (roe_rk + fcf_rk + (1 - cv_rk) + (1 - debt_rk)) / 4.0   # 4 个质量因子强制等权
r['score'] = round((1 - combo_q) * qs + combo_q * mom_rk[i], 4)  # 质量:动量 = 5:5
```

其中"四个等权"与"5:5"均**无数据依据**，是人工设定。

**GBDT（LightGBM / XGBoost）** 的做法是：不预设权重，让模型从数据中学习——能自动捕获"ROE 高但负债也高时要打折""动量超过 150% 后反而反转"这类**非线性关系与因子交互**。

"**直接上**"指：跳过修数据、补因子、做 IC 诊断三步，直接用当前 5 个（4 个来自滞后 16 个月的年报、且宇宙存在幸存者偏差的）因子训练 GBDT。后果可预测：模型会学到"哪些股票活到了 2026 年"这一伪规律，产出回测 IC 0.08、实盘 IC 0.01 的模型。

**正确顺序**：修数据时效 → 补因子至 20~30 个 → IC/IR 检验每个因子 → 建立线性基线 → 再上 GBDT，**且必须与基线对照**（提升不足阈值，如 IC 提升 < 0.01，则回退基线）。

**"人工选评分最高的 2~4 只"完全可行 —— 但有三个前提**

v1.0 中"N 提到 8~10"的建议**已撤回**：该建议基于周频自动换手的量化账户；而本场景是人工操作 10~15 万，N=8~10 既研究不过来，又稀释单仓意义。2~4 只合理，但需配套：

1. **行业 / 驱动逻辑必须分散** —— 反例：2026-09-04 实际建仓的 3 只（呈和科技 / 蓝特光学 / 华锐精密）**全部为 688 科创板**，本质等价于"1 只票加杠杆"，名义分散度 3、有效分散度约 1。约束：单行业 ≤1 只、单板块 ≤2 只。
2. **必须有硬止损** —— 2~4 只组合中单票 -50% 时组合损失与回本难度见下表。人工操作的优势恰在于**能执行规则**。
3. **分批建仓** —— 人工无执行速度优势，一次性打满的时点风险大。

| 持仓数 | 单仓权重 | 单票 -50% 时组合损失 | 回本所需涨幅 |
|---|---|---|---|
| 2 只 | 50% | -25.0% | +67% |
| 3 只 | 33% | -16.7% | +40% |
| 4 只 | 25% | -12.5% | +28% |

> 结论：**2~4 只的问题不在数量，而在"是否同质"与"有无止损"**。

### Q3：股票都退市了，要它的数据有什么意义？

**目的不是买它，而是不骗自己。**

具体案例：2015 年的乐视网 —— ROE 不低、52 周动量极强（+200%）、站上所有均线，**当前策略在 2015 年会满仓选中它**。真实结果：此后三年 -95% 并退市。

但当前宇宙来自 `fundamentals_broad.json`（2026 年抓取的**当前在市**股票），其中**不含乐视网**。因此回测中 2015 年根本不可能选中它 —— 回测自动"避开了所有曾经存在的坑"。

**后果**：-56% 的回撤被**系统性低估**，11.38% 的年化被**高估**。看到的不是"策略的历史表现"，而是"策略在幸存者中的历史表现"。

**对用户（人工、2~4 只）的实际意义**：不需要精确到小数点，但需要知道"真实回撤可能比 -56% 更差"。否则会按"年化 11%、回撤 56%"的心理预期执行，真到 -70% 时会在最糟的时点放弃系统。

**约束**：实测确认退市股财务数据免费渠道不可得（本地 `cw/` 无、东财返回 0 条）。

**折中方案 —— 双轨宇宙**：

| 轨道 | 覆盖范围 | 策略 | 说明 |
|---|---|---|---|
| 轨道 A | 有财务数据的在市股（1438 只） | 完整质量 + 动量 | 现有逻辑不变 |
| 轨道 B | 无财务数据标的（**含退市股**） | **仅动量 + 站线** | 标记 `quality_unknown` |

回测时两轨并行。这样乐视网在 2015 年会经由轨道 B 进入买池，其后续 -95% 会真实计入回撤。**产出是一个更差但更真实的数字** —— 这正是目的。

### Q4：季报 TTM 与日频 OHLCV，免费能拿到吗？通达信本地能解析吗？

**能，而且大部分已经在你的磁盘 / 接口里了**（详见 §6）：

| 需求 | 来源 | 成本 |
|---|---|---|
| 日频 OHLCV | 通达信本地 `.day`，`read_day()` 已解析 | **改 1 行** |
| 季报 TTM | 东财 DMSK 接口已返回季报 | **删 1 行过滤** |
| 退市股行情 | 通达信本地 `.day` 已保留 | 改宇宙构建来源 |
| 退市股财务 | ❌ 免费渠道无解 | 改为双轨方案 |
| 2001 年起老财务 | 本地 `cw/gpsh*.dat`（需逆向字段） | 不划算，暂不做 |

**外部免费源备选**（若将来需要）：akshare（全免费、接口丰富）、baostock（免费、历史行情与财报）；tushare 需积分。**注意：退市股历史财报普遍不在免费源覆盖范围内。**

## 11. 风险提示

1. 上述"预期提升"为业界经验区间，**必须实测验证**，不得作为承诺。
2. 5 万本金 + 周频换手 9 倍的组合，交易成本占比很高；降低换手（周频 → 双周/月频）可能是比换模型更有效的收益改善手段。
3. N=4 的组合对单票黑天鹅（财务造假、立案调查、退市）毫无抵抗力，**提高分散度优先于提高预测精度**。
4. 历史回测结论受数据质量支配；在 P0 完成前，任何"模型升级"的结论都不可信。
