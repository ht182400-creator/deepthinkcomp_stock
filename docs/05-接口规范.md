## 一、通用约定

- Base URL：`http://localhost:8899`
- 编码：UTF-8；腾讯接口返回 GBK（后端负责解码）
- 错误：HTTP 200 + `{"error": "..."}`（前端友好）；4xx/5xx 仅用于系统级错误
- 股票代码格式：`sh600519` / `sz000001` / `bj830xxx`（带市场前缀）

## 二、策略/持仓 API（继承 deepthinkstock）

### 2.1 标的下拉池
```
GET /api/pool?cls=all|sh|sz|bj
→ { total: 1771, items: [{code, name, industry, market}] }
```

### 2.2 持仓 CRUD
```
GET  /api/holdings                      → { items: [{code,name,industry,amount,dingtou,date}] }
POST /api/holdings  {code, amount, dingtou}  → { items: [...] }
POST /api/holdings/delete {codes: [...]}     → { items: [...] }
```

### 2.3 设置
```
GET  /api/settings   → {auto_track, weekly, newpos, cash, N}
POST /api/settings   → 部分更新
```

### 2.4 保存并分析
```
POST /api/analyze {force_refresh?, auto_track?}
→ {message:"分析已提交", running:true}

GET /api/analyze/status
→ {running, message, percent, result: {...}}
```

**result 结构**：
```json
{

  "cards": [{"code","name","industry","market","amount","score",
              "advice","action","desc"}],
  "selected_recommends": [{"code","name","industry","market","score",
              "advice","action","held","is_top","one_hand","fea_ratio",
              "lots","capital","desc"}],

              "advice","action","held","is_top","one_hand","fea_ratio","desc"}],
```

### 2.5 回测/对比
```
GET /api/backtest   → { "B_全样本1996+": {annualized, sharpe, max_drawdown, empty_frac, avg_turnover}, ... }
GET /api/curves     → { "B_全样本1996+": {dates:[], equity:[], ...}, ... }
GET /api/compare    → { current:{...}, prev:{...} }
```

### 2.6 报告/日志
```
GET  /api/report/md?download=0|1   → Markdown 或文件下载
GET  /report/latest                → 最新 dashboard_<信号日>.html
GET  /api/logs                     → { items: ["[2026-08-16 12:30] 消息", ...] }
GET  /api/logs/download            → analyze.log 下载
GET  /api/action_log               → { items: [{ts, signal, items:[{code,name,op,detail}]}] }
```

## 三、个股行情 API（新增，核心）

### 3.1 行情概况
```
GET /api/stock/quote?code=sh600519
→ {
    code, name, price, pre_close, open, high, low,
    change, change_pct, volume, amount, time,
    turnover_pct, amplitude_pct, outer, inner,
    pe_dyn, pb, float_mv, total_mv, volume_ratio, avg_price,
    order_book: { bids: [{price,vol}×5], asks: [{price,vol}×5] }
  }
```

### 3.2 分时
```
GET /api/stock/tick?code=sh600519&date=20260816
→ { items: [{t:"09:31", price, avg, vol, amount}, ...] }  # 240 根
```

### 3.3 五档盘口
```
GET /api/stock/orderbook?code=sh600519
→ { bids:[{price,vol}×5], asks:[{price,vol}×5], ratio, updated }
```

### 3.4 订单流（近似逐笔）
```
GET /api/stock/flow?code=sh600519&limit=50
→ { items: [{time, price, volume, direction: "buy"|"sell"}], source: "tencent" }
```

### 3.5 资金博弈
```
GET /api/stock/fund_flow?code=sh600519
→ {
    main_in, main_out, retail_in, retail_out,
    super_large, large, medium, small,   // 净额（元）
    series: [{t, main, retail, ...}]      // 分钟序列（资金博弈图）
  }
```

### 3.6 财务摘要
```
GET /api/stock/fundamentals?code=sh600519
→ {
    years: ["2021"..."2026"],
    revenue: [...], net_profit: [...],
    gross_margin: [...], net_margin: [...],
    roe: [...], debt_ratio: [...], eps: [...],
    cached_at: "2026-08-16 09:00"
  }
```

### 3.7 股东户数
```
GET /api/stock/shareholders?code=sh600519
→ { total, avg_holding, avg_amount, trend: [{date, holders}] }
```

### 3.8 新闻公告
```
GET /api/stock/news?code=sh600519&limit=10
→ { items: [{title, date, source, url}] }
```

### 3.9 历史 K 线
```
GET /api/stock/kline?code=sh600519&period=day|week|month|60|30|15|5&limit=260
→ { items: [{date, open, high, low, close, volume}], source: "tdx" }
```

### 3.10 股票搜索
```
GET /api/search?q=茅台
→ { items: [{code, name, market, pinyin}] }
```

### 3.11 系统状态
```
GET /api/sysinfo
→ { env, sources: {tencent: "ok"|"degraded"|"down", eastmoney: "...", tdx: "...", npx: "..."} }
```

## 五、接口评审意见（全栈工程专家）

1. **并发优化**：`/api/stock/*` 详情页 8 个端点前端 `Promise.all` 并发，服务端各自走缓存+降级，互不阻塞
2. **批量预留**：`/api/quote?codes=` 批量接口在 P5 实现（自选表格用），架构已预留
3. **SSE 进度**：`/api/analyze/stream` 替代轮询（P4 落地），当前 1.5s 轮询兜底
4. **幂等性**：POST /api/holdings 幂等（同 code 覆盖）；POST /api/analyze 拒绝并发重复
5. **限流**：`/api/stock/*` 走 core/rate_limiter（腾讯 5/s、东财 2/s），防轮询打爆源

## 六、个股详情完整移植（deepthinkSingle 1:1，2026-08-17）

### 6.1 架构变更

`static/js/modules/stock.js` 由"自研三列布局"改为**薄壳**：
- 渲染 `single-template.js`（SINGLE_HTML = deepthinkSingle `templates/index.html` 的完整 `<body>`，含 topbar / 自选管理 / 搜索 / K线视图 / 副图配置 / 资金流明细 / 复盘记录 / 右键菜单 / 全部 modal）
- 由 `single-app.js`（92KB，原样复制 deepthinkSingle `static/js/app.js`，挂 `window.__SINGLE_APP__`）驱动全部交互
- `single-indicators.js`（原 deepthinkSingle indicators.js，挂 `window.DTIndicators`，MACD/KDJ/BOLL/RSI 纯算法）
- CSS：`single-style.css` 缺失部分已并入 `stock.css`（全部 `#pane-stock` 前缀隔离）

### 6.2 与 deepthinkSingle 契约一致的端点

| 端点 | 说明 |
|---|---|
| GET /api/quote?code= | **聚合形状** `{quote, minute, fund, stats, finance, profit_trend, holders, company, forecast, margin, lhb, announcements, day5_funds, sentiment, north, errors}`（svc.get_all，四级降级链） |
| GET /api/kline?code=&period=&limit= | 日K/周K/月K/60/30/15/5 分（period 归一化 day/week/month/m60/m30/m15/m5） |
| GET /api/minute?code=&date= | 分时（date=YYYYMMDD 拉历史某日，供历史分时小图 modal） |
| GET /api/watchlist / POST /api/watchlist | 自选列表（action=add/remove/items） |
| GET /api/many?codes= | 批量聚合并发（自选批量表格） |
| GET /api/search?q= | 股票搜索（代码/名称/拼音/行业） |
| GET /api/announcement?code= | 公告正文（含 PDF URL） |
| **GET /api/analysis?code=** / **POST /api/analysis** | **复盘记录**（持久化 data/analysis.json，{code, note, ts}，ts 倒序，上限 500 条） |

### 6.3 新增/扩展字段

- `quote` 内：`order_book`（五档买卖）、`outer/inner`（外盘内盘）、`total_mv/float_mv`（市值亿）、`pe_dyn/pb`、`volume_ratio`、`turnover_pct`
- `north`：北向资金（沪股通+深股通合计），来自 `sources/company.get_north_holding`（报表 RPT_MUTUAL_HOLDSTOCKNORTH_STA），字段 `latest_date/holdings(万股)/hold_value/ratio/change_pct/rows`
- `minute[]`：`{t, price, avg, vol, amount}`（avg 均价线已归一化）

### 6.4 前端功能清单（与 deepthinkSingle 一致）

1. 顶部状态栏：名称/代码/巨号现价/涨跌幅/数据源/更新时间

3. 分钟视图：左列分时图+副图（可配置最多 5 个）、中列盘口（5档卖/大字现价/5档买/ob-stats 8行×2列 实时数据）+ 逐笔成交（240 条滚动，↑/↓ 切换选中）、右列市场综合（13 section）

6. 分钟资金流明细 modal（时间/主力净额/超大/大/中/小单）
7. 复盘记录 modal（保存/列表/删除）
8. 副图配置 modal（右键空白区/分时图弹出）
9. 右键菜单：副图配置/K线副图配置/资金流明细/导出CSV/立即刷新
10. 公告正文 modal（含 PDF 外链）
11. 30s 自动轮询刷新（视图=分钟时）
12. 移动端自适应（窄屏三列堆叠）
